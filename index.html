Decision Desk

选片决策台

先答四个问题，片荒立刻缩到 3—5 部候选。

Q1 心情

想放松 / 想烧脑

放松走喜剧、动画、轻爱情；烧脑走悬疑、硬科幻、社会剧情。

→ 看类型片单
Q2 时间

90 分钟 / 连刷

通勤碎片选短片集；晚上整块时间选长片；周末做三部曲马拉松。

→ 看场景推荐
Q3 人数

独居 / 合家 / 情侣

独居可重作者片，合家避惊吓，情侣偏轻喜剧与音乐传记。

→ 看场景推荐
Q4 口碑

高分 / 新片 / 冷门

补分用公开评分榜，追新看院线与持权平台，冷门走资料馆影展。

→ 看口碑榜单
Q5 画质

手机 / 投影 / 影院

手机看轻量剧情，投影看宽幅大片，影院优先新片与修复重映。

→ 看正版渠道
Q6 语言

原声 / 国语 / 字幕

练听力选原声，带娃选国语，冷门片确认官方中字再入。

→ 渠道前先核字幕
Q7 题材雷区

不血腥 / 不冗长

晕剪、重口、超长独白提前标掉，按耐受度缩片单。

→ 类型页筛标签
Q8 成本

会员 / 单片 / 免费正版

只看一部用单片租赁，常看办持权会员，公共文化片库可合法免费。

→ 正版渠道导航
By Genre

类型片单缩圈

综合站不堆全库，按常看类型给“入口＋避坑点”。

悬疑推理

本格 / 社会派 / 心理

密室、时间线、家庭秘密分开放；先确认反派动机清楚、结局可讨论。

避坑：纯靠“全程反转”噱头、无逻辑收尾的不入候选。
科幻太空

硬科幻 / 赛博 / 灾难

看设定严谨度与视效平衡；新手从太空歌剧、近未来轻科幻入门。

避坑：只堆爆炸、世界观设定前后矛盾的降权。
喜剧解压

轻喜剧 / 方言 / 群像

独居、合家、通勤都适用；优先国语清晰、不靠低俗梗的版本。

避坑：靠恶搞明星、硬凑段子的不列入主推。
动画家庭

合家欢 / 成人动画 / 短片

带娃看成长与自然，成人向看作者美术与隐喻，短片做午夜场。

避坑：无分级说明、惊吓镜头未标注的慎推。
爱情情侣

甜宠 / 现实 / 失恋后

情侣夜选轻甜不虐，单人补片可按“现实向”和“治愈向”分档。

避坑：强行煽情、第三者的套路烂梗降权。
纪录审美

自然 / 人物 / 艺术电影

慢刷、拉片、影展前补片用；优先正版修复与导演剪辑。

避坑：标题党“惊人真相”、实为剪辑搬运的不入。
By Scenario

场景推荐流

同部片不同空间体验差很多，按场景直接配。

夜

独居深夜慢刷

长镜头、纪录片、作者剧情；低音量、可暂停，配正版串流与笔记。

家

合家周末客厅

动画合家欢、自然片、轻喜剧；字幕放大、避开暗黑反派与重口。

寝

寝室短时连看

短片集、轻悬疑、≤110 分钟；不血腥、不吵邻，笔记本小屏即可。

约

情侣宅夜

轻爱情、音乐传记、城市治愈；双字幕可选，收尾不强行虐心。

通

通勤碎片

单集短片、随笔式纪录片；只存候选，不下载未知播放器。

展

影展/资料馆

修复版、国别专题、作者合集；以官方排片与授权片源为准。
